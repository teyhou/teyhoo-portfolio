# Teyhoo — Personal Portfolio

A personal portfolio website introducing my background in Computer Engineering, selected projects, and ongoing journey in web development.

## Overview

This project is a responsive, static portfolio website built to present my projects, technical interests, and developing skills in a clear and accessible format.

It is also a practical learning project where I apply web development fundamentals and improve my approach to clean, maintainable code.

## Features

- Semantic HTML structure
- Responsive layouts for different screen sizes
- CSS-based visual styling and interactions
- Accessible navigation and a skip link
- Project, skills, about, and contact sections
- Email contact link
- Reduced-motion support

## Technologies

- **HTML5** — Page structure and semantic markup
- **CSS3** — Layout, responsive design, styling, and transitions
- **JavaScript** — Reserved for potential future functionality; no JavaScript features are currently required

## Getting Started

No package installation or backend setup is required.

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

For local development, you can also use the Live Server extension in Visual Studio Code.
